公司里最不起眼、又最容易出事的设备，大概就是打印机。

它平时安静地待在角落，一旦罢工，半个办公室的人都会围过来——然后开始互相问：「你那边能打吗？」

这篇文章把我这些年装共享打印机踩过的坑整理一下。**共享本身只要三分钟，难的是它坏掉之后你不知道该从哪儿查起。**

## 主机端：四步设好共享

1. 先正确安装驱动、连接打印机，打印测试页，**确保本机能正常打印**
2. 打印机属性 → **共享**选项卡 → 勾选「共享这台打印机」，起一个共享名
3. 网络和共享中心 → 高级共享设置 →（当前配置文件需为**专用**）打开**文件和打印机共享**
4. 网络和共享中心 → 高级共享设置 → 所有网络 → 密码保护的共享 → **关闭密码保护共享**

正常情况下做完这四步，客户端就能连上了。

### 还是连不上？再查这三项

这一步是第 4 步的延伸。关掉密码保护共享之后，客户端其实是拿 `Guest` 身份来访问的——**如果系统层面把 `Guest` 挡在外面，那个开关就等于白关。**

**① 用户权限分配**

本地安全策略 → 本地策略 → 用户权限分配，检查「**拒绝本地登录**」和「**拒绝从网络访问这台计算机**」这两个名单。

正常情况下它们应该是空的：

![正常状态：两个「拒绝…」名单都是空的](/images/printer/secpol-user-rights.png)

如果里面出现了 `Guest`，来宾就永远进不来——这是最典型的连不上原因：

![异常状态：Guest 被列进了「拒绝…」名单](/images/printer/secpol-user-rights-guest.png)

**② 网络访问: 本地帐户的共享和安全模型**

本地安全策略 → 本地策略 → 安全选项 → 找到「**网络访问: 本地帐户的共享和安全模型**」，必须是「**经典**」。

![共享和安全模型必须是「经典」](/images/printer/secpol-share-model.png)

被改成「仅来宾」的话，带密码的账户会全部认证失败。

**③ 账户状态**

同一个位置，再检查三项：「**账户: 管理员帐户状态**」「**账户: 来宾帐户状态**」「**账户: 使用空密码的本地帐户只允许进行控制台登录**」。

![账户状态：管理员已启用、来宾已禁用](/images/printer/secpol-guest-account.png)

**②和③要搭配着看**：如果共享模型是「仅来宾」、来宾账户又是「已禁用」，那就是谁都连不进来。

## 客户端：两种连法

**方法一（省事）**：按 `Win + R`，输入

```
\\主机名或主机IP
```

主机名在主机上 `cmd` 里输入 `hostname` 就能看到。回车后会列出主机的共享，双击打印机就行。

**方法二（可靠）**：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加设备 → 「我需要的打印机不在列表中」→ 选「按名称选择共享打印机」→ 输入

```
\\主机名或主机IP\共享名
```

方法一更快，但依赖主机名解析；方法二更稳，尤其主机名解析不了的时候。

## 可能存在的坑

### 1. 防火墙拦截

主机能看到，但就是连不上，或者时好时坏。

**解法**：确认主机的防火墙放行了「文件和打印机共享」。如果公司装了安全软件，还要单独看它有没有拦 SMB。

### 2. 驱动装不上，或者打出来是乱码

**根因**：主机和客户端的**系统位数不一致**（一个 32 位一个 64 位），或者 Windows 版本差太多。

**解法**：在主机上，打印机属性 → 共享 → **其他驱动程序**，把 x86 和 x64 都勾上。这样客户端来连的时候，主机能直接把对应驱动推过去，客户端不用手动找。

### 3. 重启后共享就失效

每次开机都要重新连一次。

**解法**：检查主机上 **Server** 和 **Print Spooler** 两个服务的启动类型，都改成「自动」。再把客户端的连接做成快捷方式，丢进启动文件夹。

### 4. 主机 IP 变了

主机如果用自动获取 IP（DHCP），路由器一重启、租期一到，IP 就可能变。你用 `\\主机IP` 建的快捷方式全部失效。

**解法**：给主机设**固定 IP**，或者干脆改用 `\\主机名` 连——主机名一般不会变。

## 一个排查顺序

打印不出来的时候，**从上往下查，别跳步**：

1. 主机自己能打吗？→ 不能，是打印机或驱动的问题
2. 主机能被 ping 通吗？→ 不能，是网络问题
3. `\\主机名` 能打开吗？→ 不能，是共享权限、防火墙或本地安全策略的问题
4. 能打开、但连不上打印机？→ 是驱动问题
5. 全都能连、但打出来是乱码？→ 还是驱动问题

大部分情况下，**第 2 步就能定位**。

## 最后

共享打印机是典型的「能用就行，坏了抓瞎」。它不像软件问题那样有报错日志，它的表现永远只有一句「打印不出来」。

所以我把这份记录留着——**下次它再罢工，我至少知道从第几步开始查。**
