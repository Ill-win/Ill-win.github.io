公司里最不起眼、又最容易出事的设备，大概就是打印机。

它平时安静地待在角落，一旦罢工，半个办公室的人都会围过来——然后开始互相问：「你那边能打吗？」

这篇文章把我这些年装共享打印机踩过的坑整理一下。**共享本身只要三分钟，难的是它坏掉之后你不知道该从哪儿查起。**

## 主机端：三步设好共享

1. **先确认本机能打印。** 别急着管共享，主机自己先打一张测试页。这一步不过，后面全是白费功夫。
2. 控制面板 → 设备和打印机 → 右键目标打印机 → **打印机属性** → **共享**选项卡 → 勾选「共享这台打印机」，起一个名字。
3. 控制面板 → 网络和共享中心 → 高级共享设置 → 打开**文件和打印机共享**。

## 客户端：两种连法

**方法一（省事）**：在文件资源管理器的地址栏输入

```
\\主机名
```

或者

```
\\主机IP
```

回车后会列出主机共享的设备，双击打印机就行，驱动通常会自动装。

**方法二（可靠）**：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加设备 → 「我需要的打印机不在列表中」→ 选「按名称选择共享打印机」→ 输入

```
\\主机名\共享名
```

方法一更快，但依赖主机名解析；方法二更稳，尤其主机名解析不了的时候。

## 最容易踩的七个坑

### 1. 主机 IP 变了

主机如果用自动获取 IP（DHCP），路由器一重启、租期一到，IP 就可能变。你用 `\\主机IP` 建的快捷方式全部失效。

**解法**：给主机设**固定 IP**，或者干脆改用 `\\主机名` 连——主机名一般不会变。

### 2. 提示「输入网络凭据」

连共享时弹窗要账号密码，输什么都不对。这是最常见、也最烦人的一个。

**先试简单的**：在主机上关掉「密码保护的共享」（控制面板 → 网络和共享中心 → 高级共享设置 → 所有网络）。或者给两台机器建**同名同密码**的账号。

**还不行**，就要去改本地安全策略了——见下面「进阶」一节。

### 3. 驱动装不上，或者打出来是乱码

**根因**：主机和客户端的**系统位数不一致**（一个 32 位一个 64 位），或者 Windows 版本差太多。

**解法**：在主机上，打印机属性 → 共享 → **其他驱动程序**，把 x86 和 x64 都勾上。这样客户端来连的时候，主机能直接把对应驱动推过去，客户端不用手动找。

### 4. 防火墙拦截

主机能看到，但就是连不上，或者时好时坏。

**解法**：确认主机的防火墙放行了「文件和打印机共享」。如果公司装了安全软件，还要单独看它有没有拦 SMB。

### 5. 重启后共享就失效

每次开机都要重新连一次。

**解法**：检查主机上 **Server** 和 **Print Spooler** 两个服务的启动类型，都改成「自动」。再把客户端的连接做成快捷方式，丢进启动文件夹。

## 进阶：改本地安全策略

前面七条都排除了，还是提示「拒绝访问」、或者一直弹凭据框，那就要往下挖了。

按 `Win + R` 输入 `secpol.msc` 打开**本地安全策略**，重点看下面三处。

### 1. 本地策略 → 用户权限分配

检查「**拒绝从网络访问这台计算机**」和「**拒绝本地登录**」这两个名单。

它们是**黑名单**——账号只要出现在里面，别的设置怎么调都没用。正常情况应该是空的。

![用户权限分配：检查「拒绝…」名单是否为空](</images/printer/secpol-user-rights.png>)

### 2. 本地策略 → 安全选项 → 网络访问: 本地账户的共享和安全模型

这一项决定了别人从网络连过来时，用**什么身份**做验证：

- **经典**（默认，也是推荐值）：用对方的真实账号密码验证。共享权限、文件权限都按正常规则生效
- **仅来宾**：所有人都以 Guest 身份访问。Guest 一旦被禁用，访问直接被拒

打印机连不上、或者一直弹凭据框，**先看这里是不是被改成了「仅来宾」**。

![网络访问: 本地账户的共享和安全模型 → 经典](</images/printer/secpol-share-model.png>)

### 3. 本地策略 → 安全选项 → 账户: 来宾账户状态

确认是「**已禁用**」。这是默认值，也是安全值。

⚠️ 注意第 2 项和第 3 项的**组合**：如果第 2 项是「仅来宾」，而第 3 项又是「已禁用」，那结果就是——谁也别想连进来。这两项必须搭配着看。

![账户: 来宾账户状态 → 已禁用](</images/printer/secpol-guest-account.png>)

## 一个排查顺序

打印不出来的时候，**从上往下查，别跳步**：

1. 主机自己能打吗？→ 不能，是打印机或驱动的问题
2. 主机能被 ping 通吗？→ 不能，是网络问题
3. `\\主机名` 能打开吗？→ 不能，是共享权限、防火墙或本地安全策略的问题
4. 能打开、但连不上打印机？→ 是驱动问题
5. 全都能连、但打出来是乱码？→ 还是驱动问题

大部分情况下，**第 2 步就能定位**。


## 最后

共享打印机是典型的「能用就行，坏了抓瞎」。它不像软件问题那样有报错日志，它的表现永远只有一句「打印不出来」。

所以我把这份记录留着——**下次它再罢工，我至少知道从第几步开始查。**
